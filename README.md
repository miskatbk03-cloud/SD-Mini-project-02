## About

Food Mood is a single-page, fine-casual restaurant website built with **HTML5** and **Tailwind CSS** (via CDN). It uses **no JavaScript**: every interaction is done with HTML and Tailwind utility classes.

## Sections

- **Navbar:** logo, anchor links (`#home`, `#about`, `#menu`, `#reservation`), "Book a Table" button, and a CSS-only mobile menu (hidden checkbox + `peer-checked`)
- **Hero:** tagline, short description, "Explore Menu" and "Reserve Now" buttons
- **About / Our Story:** restaurant story, ingredients, chef's specialty, image
- **Featured Menu:** 6 dishes with images, descriptions, prices and category badges
- **Reservation, Contact and Footer:** booking form, opening hours, location, contact info

## Tailwind features used

- Responsive layout with `sm:`, `md:` and `lg:` prefixes
- Flexbox and grid layouts, spacing, typography, shadows, rounded corners
- Hover effects (`hover:`), card zoom (`group-hover:scale-105`), input focus rings (`focus:ring-4`)
- Smooth scrolling with `scroll-smooth`

## How to run

1. Download or clone this repository.
2. Open `index.html` in Google Chrome. An internet connection is needed for the Tailwind CDN and Unsplash images.
3. Press `F12`, then `Ctrl + Shift + M` to test mobile, tablet and desktop widths.
